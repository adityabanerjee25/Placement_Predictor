Machine Learning Architecture & Specs

Scikit-learn pipeline mechanics, data transformation, and inference parameters.

Pipeline Engineering

The machine learning engine implements a unified sklearn.pipeline.Pipeline incorporating automated ColumnTransformer preprocessing.

  • Numerical Transformation: StandardScaler() normalizes 14 continuous features to zero mean and unit variance.
  • Categorical Transformation: OneHotEncoder(drop='first', handle_unknown='ignore') handles multi-class branches and tier strings.
  • Model Serialization: Clean joblib artifacts ensure exact feature mapping alignment between training and production inference.
